# Roadmap

These are proposed directions, not delivery promises. The current release is a sandbox prototype.

## Available in v0.1.0

- [x] Three seeded savings circles and an agent briefing
- [x] Nine agent tools with a streamed activity trace
- [x] PayPal sandbox contributions and treasurer-triggered payouts
- [x] Member replies and treasurer-reviewed instalment plans
- [x] Six language choices and an in-app message outbox
- [x] Contribution history across circles

## Foundation for a controlled pilot

- [ ] Real authentication, roles and server-side authorization for every mutation
- [ ] Transactional database, migrations and concurrency-safe accounting
- [ ] Verified payment webhooks and reconciliation of pending/failed payouts
- [ ] Durable agent jobs, rate limits and audit logs
- [ ] Automated tests for payment state transitions and approval boundaries
- [ ] Privacy controls, retention policy and member consent
- [ ] Native-speaker review of templates and generated-message quality

## Product expansion

- [ ] WhatsApp Business API delivery and inbound messages
- [ ] Local payment rails, including evaluation of PayShap
- [ ] Accessible mobile flows and usability work with real treasurers
- [ ] Member-controlled export of payment history

Any use of payment records in lending, housing or insurance needs separate validation and review. That is outside this demo’s capabilities.
