# Rotapot v0.1.0 — The first circle

The first tagged release of Rotapot: an AI treasurer’s assistant for stokvels, mukando and diaspora savings circles, built for the PayPal AI Hackathon 2026.

**[Try the demo](https://rotapot.simakk.co.za) · [Watch the two-minute film](https://youtu.be/6AdlBTQAcvI) · [Devpost entry](https://devpost.com/software/rotapot)**

## In this release

- **One briefing across three circles.** Claude reads the books, writes reminders and proposes ready payouts, with a live tool trace.
- **PayPal contribution and payout flows.** Orders v2, JavaScript SDK checkout and Payouts v1, all in sandbox.
- **Members can reply.** Payment verification and instalment-plan proposals, with treasurer approval.
- **Six language choices.** Shona, Ndebele, isiZulu, Sesotho, Setswana and English in the demo’s in-app conversation.
- **A visible record of reliability.** Contribution history, on-time rates and streaks across circles.
- **A documented starting point.** Setup, architecture, judge walkthrough, roadmap and CI.

## Try it locally

Download the source archive below, then run `npm ci`, copy `.env.example` to `.env.local`, add your own sandbox/model credentials and run `npm run dev`. Node.js 22 is used by CI. See the README for mock mode and model configuration.

## Prototype limits

No real money moves. WhatsApp delivery is simulated in an in-app outbox. Historical records are seeded. Demo sign-in and JSON storage are not production security or accounting infrastructure. Native-speaker review remains planned.

This release marks the working hackathon prototype, not a production financial service.
